# Support

Use GitHub Discussions when available for usage questions and GitHub Issues for
reproducible defects or bounded feature requests. Security reports must follow
[SECURITY.md](SECURITY.md) and remain private.

Before filing a defect, use the current `main` branch or latest release, run the
project verification commands documented in `far/CONTRIBUTING.md`, and attach a
minimal reproduction with sensitive values removed. Maintainer response times
are best-effort; no service-level agreement is provided.
